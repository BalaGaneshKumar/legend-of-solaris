# The Legend of Solaris

A story series in eight books, shown as page-turning books on a web page.
It works on phones, tablets and computers.

- Open the site: `https://balaganeshkumar.github.io/legend-of-solaris/`
- Open one book directly, for example: `.../#book-p41`
  (ids: `vamp`, `solaris`, `p311`, `p312`, `p321`, `p322`, `p41`, `p42`)

The site is plain HTML, CSS and JavaScript. It has no server, no login,
no forms, no cookies and no tracking.
